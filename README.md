## How to read a score

The pass rate is the weakest number in these reports. The corpus was generated by AndroidX from its own player, so agreeing with it is partly a measure of resembling that player. Read the cross-lane split first: it separates *this player disagrees* from *every player disagrees*, and only the first is a bug report.

See `docs/design/RC_CONFORMANCE.md` on `main` for what the lane does and does not measure.
